## 🚀 Как запустить готовое приложение (в 1 клик):

Дважды щелкните по файлу:
👉 **`Start_Application.command`** (или **`Запустить_Приложение.command`**)

Приложение запустит локальный сервер и автоматически откроет в браузере (Chrome / Safari) интерактивный интерфейс:
- **📁 Цифровой шкаф:** просмотр всех вещей гардероба с реальными фото, фильтрами категорий, стилей, теплоты и поиском;
- **➕ Добавление вещей с фото:** выбор любого изображения с компьютера (JPEG, PNG, WEBP), предпросмотр и кнопка **«✨ Запустить анализ AI (ONNX)»** с автоматическим определением категории и цвета;
- **✨ Подбор образов (AI):** выбор города, даты, часа, живой прогноз Open-Meteo API или ручной ввод параметров погоды, выбор события («учёба», «работа», «свидание», «прогулка», «спортзал») и генерация **3 вариантов образов** с фото входящих вещей и текстовыми обоснованиями!

## 📌 Структура проекта по шагам Технического задания

- 📂 `01_Этап_1.1_Техническое_задание/` — Утвержденное ТЗ по ГОСТ 19.201-78 (`.docx` и `.pdf`), аналитический отчет с обзором аналогов.
- 📂 `02_Этап_2.1_Архитектура_и_модель_БД/` — Архитектурная спецификация (Clean Architecture, MVVM), реляционная схема SQLite/Room (`schema.sql`), Kotlin сущности и DAO.
- 📂 `03_Этап_2.2_Хранилище_гардероба_и_ONNX/` — Репозиторий «Цифровой шкаф» (`wardrobe_repo.py`), классификатор ONNX (`onnx_classifier.py`), модуль цвета (`color_extractor.py`), тесты.
- 📂 `04_Этап_2.3_Метеоданные_и_алгоритм_подбора/` — Клиент Open-Meteo REST API (`weather_service.py`), автономный ручной ввод, движок многокритериального подбора (`recommendation_engine.py`), тесты.
- 📂 `05_Этап_2.4_Пользовательский_интерфейс_UI/` — Отчет и Compose Multiplatform исходники экранов на Kotlin (`.kt`).
- 📂 `06_Этап_2.5_Комплексное_тестирование_и_ПМИ/` — Программа и методика испытаний (ГОСТ 19.301-79, `.docx`), протокол испытаний (`.docx`), автотесты 9 сценариев (`run_all_tests.py`, 100% успех).
- 📂 `07_Этап_3.1_Документирование_и_сдача/` — Пояснительная записка (ГОСТ 19.404-79, `.docx`), Руководство оператора (ГОСТ 19.505-79, `.docx`), Листинги (ГОСТ 19.101-77), Акт сдачи-приемки на оценку «Отлично».
- 📂 `ClothesHelper_App/` — Полный проект Kotlin/Compose Desktop (`build.gradle.kts`, `libs.versions.toml`) и готовое интерактивное приложение (`web_app.py`, `run_app.py`, `wardrobe.db`, `images/`).
