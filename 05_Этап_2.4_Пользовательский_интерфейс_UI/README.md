# Этап 2.4: Пользовательский интерфейс (UI)

## 1. Архитектура экранов (Material Design 3)
1. **Экран «Цифровой шкаф» (Каталог):** адаптивная сетка карточек с фото, фильтры категорий/стилей/сезонов, поиск по названию, счетчик вещей, кнопка добавления.
2. **Экран «Карточка вещи»:** выбор фото, кнопка «Анализ AI (ONNX)», автозаполнение категории и цвета с возможностью ручной правки, поля теплоты, стиля и влагозащиты, валидация.
3. **Экран «Погода и параметры подбора»:** выбор города, дня и часа, карточка метеоусловий, тумблер ручного ввода, кнопки выбора события («учёба», «работа», «свидание», «прогулка», «спортзал»).
4. **Экран «Рекомендации образов»:** отображение 3 готовых комплектов с миниатюрами вещей, бейджами и связным обоснованием; индикатор дефицита гардероба.

## 2. Состав файлов этапа
- `Отчет_Этап_2.4_Пользовательский_интерфейс.docx` – официальный отчет этапа;
- `WardrobeCatalogScreen.kt` – Compose UI экран каталога «Цифровой шкаф»;
- `OutfitRecommendationScreen.kt` – Compose UI экран рекомендаций;
- `Theme.kt` – палитра и темы Material Design 3.
