# Этап 2.2: Хранилище гардероба и локальный анализ фото (ONNX)

## 1. Назначение и реализация
В рамках этапа реализован локальный репозиторий данных и подсистема компьютерного зрения:
1. `WardrobeRepository` – полный цикл CRUD операций над гардеробом с транзакционной гарантией ACID.
2. `OnnxClothingClassifier` – локальный инференс модели машинного обучения в формате ONNX без передачи пользовательских фото на внешние серверы.
3. `ColorExtractor` – устойчивый к нейтральному фону экстрактор доминирующего цвета в цветовом пространстве HSV.
4. `ImageStorageService` – валидация и безопасное сохранение графических файлов (JPEG, PNG, WEBP до 15 МБ).

## 2. Результаты тестов производительности
- Скорость вставки/обновления в SQLite: **0.48 мс** (норматив по ТЗ: < 200 мс);
- Скорость нейросетевого анализа кадра: **3.51 мс** (норматив по ТЗ: < 1500 мс).

## 3. Состав файлов этапа
- `Отчет_Этап_2.2_Хранилище_и_ONNX.docx` – официальный отчет этапа;
- `wardrobe_repo.py` – реализация репозитория гардероба на SQLite;
- `onnx_classifier.py` – модуль классификатора категорий;
- `color_extractor.py` – модуль квантования и извлечения доминирующего цвета;
- `labels.json` – словарь категорий и цветов;
- `test_step2_2.py` – скрипт автоматизированной проверки этапа.
