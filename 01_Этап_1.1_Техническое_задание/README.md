## 1. Назначение этапа
Разработка и утверждение технического задания на создание программного продукта «Система интеллектуального подбора одежды “Умный гардероб”» (шифр: WARDROBE-AI, проект: ClothesHelper) в соответствии с ГОСТ 19.201-78 и ГОСТ 2.105-2019.

## 2. Результаты выполнения работ
1. **Анализ предметной области:** выявлены проблемы когнитивной перегрузки пользователей при ежедневном выборе одежды и отсутствие на рынке решений, сочетающих десктопный интерфейс, локальное машинное обучение (гарантия приватности фото) и многофакторный учет погодных явлений (ветер, осадки, температура).
2. **Сравнительный анализ аналогов:** исследованы системы Acloset, Cladwell, Whering. Сформирована таблица конкурентных преимуществ ClothesHelper.
3. **Обоснование технологического стека:** утверждены Kotlin 2.0, Compose Multiplatform Desktop (Skiko), SQLite/Room KMP, ONNX Runtime, Ktor Client, Gradle 8.x (libs.versions.toml).
4. **Утвержденное ТЗ:** оформлен официальный документ ТЗ объемом 28 страниц по требованиям кафедры № 41 ГУАП.
